// Case Study

일하는 방식 예시

실제 겪었던 문제 해결 과정을 일반화한 예시입니다.

🔍 "정책이 안 먹힌다"는 신고 — 콘솔이 아니라 에이전트 로그부터

배포한 정책이 특정 단말에만 적용되지 않는다는 보고가 들어왔을 때, 콘솔 화면상으로는 "정상 배포됨"으로 표시되어 있었습니다. 하지만 콘솔 표시를 그대로 믿지 않고 해당 단말의 에이전트 로그를 직접 확인하는 순서로 접근했습니다.

  1. 콘솔에서 "정상"으로 보여도 진짜 상태는 아닐 수 있다고 가정
  2. 대상 단말에 원격 접속해 에이전트 로그 파일을 직접 열람
  3. 로그에서 실제 에러 코드와 실패 시점을 확인
  4. 원인을 좁힌 뒤 재현 조건을 정리해 재발 방지 문서로 기록
